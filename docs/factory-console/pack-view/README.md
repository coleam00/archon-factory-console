# The factory view file for Wirasm/archon-software-factory

`factory-view.json` is the curated presentation file for the pack at commit b62ec7b20 (the
version with `how-it-works.md`). It is copied into `<installed pack>/.shared/factory-view.json`
for the demo until the owner's own pack copy ships it. Check it against a pack tree with
`bun run check:factory-view <pack dir> --view docs/factory-console/pack-view/factory-view.json`.
